# 华辰服饰产品手册

## 产品分类

### 1. 商务系列

适用于企业办公、商务会议等场景。

主要产品：

-   商务衬衫
-   西装外套
-   商务裤

### 2. 休闲系列

主要面向年轻消费者。

产品特点：

-   舒适面料
-   简约设计
-   日常通勤适用

### 3. 运动系列

面向户外运动和休闲场景。

特点：

-   透气
-   快干
-   耐磨

## 产品价格范围

商务衬衫： 200-500元/件

休闲外套： 300-800元/件

运动服套装： 400-1000元/套

## 产品交付周期

常规产品： 15-30天

定制产品： 30-60天
