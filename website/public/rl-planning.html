一、学习原则与三个月目标

主线严格遵循 1 → 2 → 4 的顺序；线性规划不依赖主线，作为论文数学建模能力的长期并行训练。

执行边界：《深度学习的数学》只用于弄清神经网络、梯度下降、链式法则、反向传播和卷积的原理，书中 Excel 实现全部跳过。PyTorch 阶段不追逐复杂网络结构，以能够独立跑通数据加载、训练、验证、保存模型和 MNIST 识别为合格线。
MONTH 01 · DAY 1-30打基础

数学原理 → PyTorch 工具

前 7 天完成数学原理，随后用 23 天掌握 PyTorch 平台和基础应用。

  • 能手推梯度下降、链式法则和反向传播
  • 能解释 Tensor、Autograd、Module、Optimizer
  • 独立完成 MNIST 训练、评估和模型保存
MONTH 02 · DAY 31-60价值方法

RL 基础 → Q-Learning → DQN

从 MDP、Bellman 方程和表格方法入手，再把 PyTorch 用到 DQN。

  • 区分状态价值、动作价值和优势函数
  • 实现动态规划、MC、TD、Q-Learning
  • 在 CartPole 跑通 DQN 并解释关键机制
MONTH 03 · DAY 61-90策略方法

策略梯度 → Actor-Critic → PPO

交叉阅读 EasyRL 与《边做边学》，通过多轮复现和对比形成算法地图。

  • 实现 REINFORCE、Actor-Critic、A2C、PPO
  • 对比 DQN 与 PPO 的适用场景和训练曲线
  • 形成可复用实验模板与三个月复盘报告

五、环境与验收标准

环境只服务于可复现实验。安装命令需在你确认后执行，本页面不会自动安装任何依赖。

建议环境

  1. Python 3.10 或 3.11，独立虚拟环境。
  2. torch torchvision numpy pandas matplotlib jupyter
  3. gymnasium stable-baselines3 用于 DRL 对照实验。
  4. pulp 或 GLPK 用于验证线性规划模型。

代码目录建议

  • math-notes/：公式推导和概念图
  • pytorch-basics/：张量、Autograd、MNIST
  • rl-labs/：Q-Learning、DQN、PPO
  • lp-algorithms/：单纯形、最短路、最大流、最小费用流

三个月完成标准

  1. 不看书能解释反向传播为何成立。
  2. 不复制整段代码能写出 PyTorch 训练与验证循环。
  3. 能从 Bellman 方程说明 Q-Learning 与 DQN 的关系。
  4. 能解释 DQN、Actor-Critic、PPO 各自解决什么问题。
  5. LP 第 1-4 章代码有测试，结果可与求解器交叉验证。
  6. 面对论文中的优化模型，能识别变量、目标函数和约束。

复习机制

  • 第一次：读懂概念并跑通最小例子。
  • 第二次：关掉书，按自己的结构重新实现。
  • 第三次：对比算法、画曲线、解释失败案例。
